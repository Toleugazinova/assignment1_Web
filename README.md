Objective
The main goal of this assignment is to learn the core principles of web development using HTML5 and CSS3. 
Key goals include:
- Creating a well-structured web page using basic and intermediate HTML elements.
- Working with text formatting, lists, links, images, tables, and form controls.
- Understanding and applying CSS styling via Inline, Internal, and External styles.
- Utilizing CSS Selectors (Element, Class, ID), the Box Model, Sizing units, Positioning, and Floats.
- Publishing the project via GitHub Pages.
